  ---
  Project Summary: Job Search Automation Agent (CV Optimizer)

  This project automates job searching for Private Equity / Investment roles in Europe, using AI to score job matches and generate
  tailored CVs and cover letters.

  ---
  What the Project Does:

  1. Scrapes job postings from multiple sources (Remotive, Adzuna, LinkedIn, Greenhouse, Lever, company career sites)
  2. AI Scores each job using LLM (Ollama free/local or Claude AI) based on your profile
  3. Stores jobs in SQLite database (jobs.db)
  4. Generates tailored CVs (.docx + .pdf) and cover letters (.txt) for top matches
  5. Creates daily HTML reports with top job recommendations
  6. Supports email notifications with daily digests

  ---
  Your Personalization:

  - Search Keywords: PE, M&A, Investment Analyst, Deal Advisory, Corporate Development, etc.
  - Target Locations: Luxembourg, Berlin, Frankfurt, Zurich, Brussels, Geneva
  - LLM: Uses gemma3:1b by default (free local), or Claude API with key
  - Scoring Instructions: Boost scores for PE/Finance roles, penalize pure Data Science roles
  - Candidate Profile: Master's student in Business Analytics/Data Science, PE/VC club experience, Real Estate investment background

  ---
  How to Use:

  # Install deps
  pip install -r requirements.txt

  # Run full pipeline (search → score → report → email)
  python main.py run

  # Just search
  python main.py search

  # Generate CV for job ID 5
  python main.py generate-cv 5

  # List high-scoring jobs
  python main.py list-jobs --min-score 0.7
